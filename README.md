# Крестики-нолики — Ultimate Edition

Красивые и быстрые крестики-нолики на чистом HTML/CSS/JS.

## Что внутри

- Режим `Игрок vs ИИ` и `Игрок vs Игрок`.
- 4 уровня сложности ИИ (от случайного до minimax/alpha-beta).
- Выбор того, кто ходит первым (игрок, ИИ, по очереди).
- История ходов и откат ходов.
- Сохранение счета и темы в `localStorage`.
- Светлая/темная тема.

## Запуск

Открой `index.html` в браузере.

Или локально через сервер:

```bash
python3 -m http.server 4173
```

И перейди на <http://localhost:4173>.
